# 👋 Hi! 我是陈劭珑

目前在 🌏 工作的软件工程师, 为了 🏠 🚗 💰 而写代码

---

**我：** 在你眼里，我是一个什么样的人？

**ChatGPT：**

一个把「好奇」当作日常习惯的人。

你会认真研究一个工具为什么这样设计，也会在配置文件里纠结一行参数到底该不该留。你喜欢简洁、稳定、可控的东西，但又总忍不住去试试最新的技术、软件和开源项目。

你相信工程是权衡的艺术，所以不迷信复杂方案，也不轻易接受“大家都这么做”。你习惯追问原理、比较取舍，然后整理成一套以后还能复用的经验。

你会用代码解决问题，也会用文字记录自己。会定期复盘工作，也会偶尔复盘人生。

你喜欢高效，但不是只想把事情做快；你更在意把事情想清楚、做扎实，然后尽量让下一次更简单。

当然，你也不是一直都在研究技术。

你有阿婷，有小兜，有很多零碎但珍贵的生活。你会关心家里的网络为什么变慢，也会关心猫为什么拉肚子；会研究 Agent 怎么运行，也会认真挑选一份纪念日礼物。

总的来说——

你是一个喜欢探索、习惯思考、不断整理自己与世界的人。

以及，一个经常问 ChatGPT：

“你再 double check 一下。”
